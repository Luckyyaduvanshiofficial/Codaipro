# Type source and licensing

The `CodaiPro` wordmark letterforms are native SVG path outlines from **Inter Display SemiBold**, with a purpose-drawn, angled replacement dot on `i`. The reference font is distributed by the **Inter Project Authors**.

Official source and license information: <https://github.com/rsms/inter> (SIL Open Font License 1.1 and Apache License 2.0 notices, depending on distribution/source). Verify the applicable notices if the font itself is ever redistributed. **No font binaries are included or supplied.**

The `branding/source/logo-editable-typography.svg` file contains SVG `<text>` for future editing and is not intended as a deployable logo; the user will need an appropriately licensed local font if editing the type. Final `branding/final/logo-*.svg` files use outlined paths, not a system font dependency.
