Codai Pro runs a real language model on your own machine, in its own window. No internet, no accounts, no API keys. The model downloads once on first launch, then everything works offline. Made for lab exams, coding competitions, and any room where the network is off limits.

Section 01

The syllabus

  1. 01

    Built for the lab

    Designed for exam halls and university machines where the network is locked down and installs are not an option.

  2. 02

    Your code never leaves

    Inference happens on your CPU. Nothing is uploaded, logged, or phoned home. Privacy is the default, not a setting.

  3. 03

    Real models, local hardware

    Runs quantized GGUF models through llama.cpp — Qwen3.5, Gemma 3, and Qwen2.5-Coder, chosen for small machines and short patience.

  4. 04

    Install it, or carry it

    Use the desktop installer on your own machine, or copy the portable folder to a USB stick and run it between labs without installing anything.

  5. 05

    Light on old machines

    Tuned for 4 GB of RAM and older CPUs. If the lab computer can run a normal desktop app, it can run Codai Pro.

  6. 06

    Speaks many languages

    Python, JavaScript, Java, C++, and more. Generation, explanation, debugging, and optimization in one chat window.

Which model?

You do not have to choose before you start. The installer ships with Qwen3.5-0.8B selected and downloads it on first launch, so the app works out of the box. Want a different brain? Drop its .gguf into the models folder and set model_name in config.json, or set model_url and let Codai Pro fetch it.
